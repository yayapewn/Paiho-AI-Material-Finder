# Material Hub material library

This GitHub Pages version contains 100 verified public Material Hub records, replacing the former 22 demo records. The library displays 20 records per page and opens matching images, descriptions, specification tables and official detail links. Unknown values remain empty instead of being invented.

The 100 local JPEGs in public/assets/materials are actual source images exported from normally rendered public pages. Image URLs use Vite BASE_URL to work beneath /Paiho-AI-Material-Finder/. They no longer depend on hotlink requests to Paiho at runtime. Original image and detail URLs remain in data/materials.json. Text was captured October 2, 2026; public images and current links were checked October 19, 2026.

Validation: 100 unique records and bundled JPEGs checked; TypeScript check; browser verification of all five library pages and an image/details preview.

This change addresses the material library and previews. It does not enable or validate the separate AI model service on static GitHub Pages.
